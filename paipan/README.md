# 排盘引擎（paipan）

给 `data/` 里全部 117 个比赛命例排出**八字盘**和**紫微斗数盘**，结果存在 [`../charts/`](../charts/)。排盘结果是确定的，同一输入每次都一样。

| 盘 | 引擎 | 许可证 |
|---|---|---|
| 八字 | [lunar-python](https://github.com/6tail/lunar-python) 1.4.8（6tail「寿星万年历」系列，与 lunar-javascript 同源） | MIT |
| 紫微斗数 | [iztro](https://github.com/SylarLong/iztro) 2.5.8 | MIT |

```bash
pip install lunar-python==1.4.8
(cd paipan/ziwei && npm install)
python paipan/build_charts.py      # 重新生成 charts/bazi/*.json 与 charts/ziwei/*.json
```

## 出生时间的三种口径

同一条出生记录可以有三种读法，排出的时柱可能不同：

| 口径 | 怎么算 | 何时有值 |
|---|---|---|
| `stated`（默认） | 原文只写时辰（如「巳时」）的，就用这个时辰（`hour` 取时辰中点）；原文写了钟点的，扣掉当时生效的夏令时，得到当地标准时间 | 有出生时间就有 |
| `clock` | 原文钟点，原样使用（不扣夏令时） | 原文写了钟点 |
| `true_solar` | 真太阳时 = 标准时间 + 4 分钟 ×（出生地经度 − 时区中央经线）+ 均时差 | 原文写了钟点，且出生地有坐标 |

- 夏令时和历史时区按 IANA 时区数据库自动判断，例如香港 1941–1979 年、台湾 1945–1979 年、中国大陆 1986–1991 年的夏令时，马来西亚、新加坡 1982 年前的 UTC+7:30，台湾 1945 年前的 UTC+9。
- 出生地坐标见 [`places.json`](places.json)。只写到省或国家的，取首府近似并标 `precision: region`；「中国大陆」「美国」这类范围太大的不算真太阳时。
- 117 个命例中，有 **12 个**的时柱会因口径不同而变化（`hour_pillar_varies: true`），用其他口径评测时要特别注意这些命例。

**为什么默认用 `stated`**：它最贴近出题老师写下的内容，只在钟点上去掉夏令时这一项公认的偏差。真太阳时的经度修正在海外命例上很大（吉隆坡约 −73 分钟），出题老师是否这样算无从得知，所以作为备选口径提供，而不是默认值。

## 其他约定

- **八字**：年柱以立春换年，月柱以节换月，**日柱在 23:00 换日**（子初换日）：23:00–23:59 出生（晚子时）的日柱取次日，和时柱一致（lunar-python `EightChar.setSect(1)`）。lunar-python 默认的「晚子时日柱算当天」会让日柱取当天、子时天干却按次日起，拼成一个日主错位的盘；出题老师也是按 23 点换日出题的（2017 年第 7b 命例注明「比前命迟23个小时出生」，2020 年第 2 命例注明「特别注意此命的出生时间在11:50pm」）。全库 5 个晚子时命例另在 `alternatives.day_kept_at_23h` 给出按当天算的日柱。起运按「三天折一年」，大运年龄为虚岁。
- **紫微斗数**：按 `stated` 的时辰起盘。iztro 的年按农历正月初一换、月按农历月份，所以它给出的年柱、月柱可能与八字不同，这是两门术数的约定不同，不是排错。
- **一致性自查**：`build_charts.py` 运行完会比对两个引擎各自算出的日柱和时柱。两者都在 23 点换日，117 个命例全部一致。

## 输出字段

`charts/bazi/<年份文件>.json` 的 `charts[person_id]`：

| 字段 | 说明 |
|---|---|
| `time` | 三种口径下的出生时间与时辰、出生地坐标、时区、夏令时分钟数 |
| `chart` | 默认口径的完整八字盘：四柱（天干十神、地支藏干及十神、纳音、十二长生、旬空）、日主、胎元、命宫、身宫、起运、九步大运、出生年至比赛年后两年的流年 |
| `alternatives` | 其他口径下的四柱；晚子时命例另有按「晚子时日柱算当天」的日柱（`day_kept_at_23h`） |
| `hour_pillar_varies` / `day_pillar_varies` | 不同口径下时柱 / 日柱是否不同 |

`charts/ziwei/<年份文件>.json` 的 `charts[person_id]`：五行局、命主、身主、命宫与身宫所在地支，以及十二宫各自的天干地支、主星（含亮度和四化）、辅星、杂曜、长生十二神、大限岁数。

2013 年第 16 题要求反推出生时辰，该命例只有年、月、日三柱，没有紫微盘。
